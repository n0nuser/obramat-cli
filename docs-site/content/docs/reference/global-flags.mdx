| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--debug` | bool | `false` | log every http request to stderr |
| `--error-format` | string | `text` | error rendering on stderr: text or json |
| `--format` | string | `json` | output format: json, jsonl, pretty, toon |
| `--no-color` | bool | `false` | no colour in pretty output (also NO_COLOR) |
| `--no-input` | bool | `false` | never prompt; fail when input is missing |
